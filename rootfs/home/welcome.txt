Welcome to arcOS.

On a graphical screen arcOS starts its desktop: this terminal is the
Terminale window (also in the dock).

This volume (sys:) holds the system and your files:

  sys:/system/drivers   the driver store: every driver this computer can use
  sys:/inbox            drop a driver package (.adp) here and it installs itself
  sys:/home             your files
  sys:/home/arcscript   programs in ArcScript, the arcOS language
  sys:/store            programs you can install (install busybox, install lua)

arcOS also runs Linux and Windows x86-64 programs: see docs/compat.md.

Try: help, dev, drv, vol, ls sys:/system/drivers,
or: cd sys:/home/arcscript, then hello.as
or: install busybox, then seq 1 5
or: display (screen resolutions), play sys:/system/sounds/avvio.wav
